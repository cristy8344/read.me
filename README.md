COVID-19 Data Analysis: NOIR Data Types
Project Overview

This project analyzes COVID-19 data using Python and the NOIR framework: Nominal, Ordinal, Interval, and Ratio data types. The goal is to identify variables from the dataset, create an ordinal variable, calculate appropriate summary statistics, and visualize the data using the Pandas, Matplotlib, and Seaborn libraries.

Dataset

The dataset contains COVID-19 information by state and date. The variables used in this project include:

state — State where the COVID-19 data was recorded
date_updated — Date the record was updated
tot_cases — Total number of COVID-19 cases
new_cases — Number of new COVID-19 cases
tot_deaths — Total number of COVID-19 deaths
new_deaths — Number of new COVID-19 deaths
new_historic_cases — Number of newly reported historic cases
